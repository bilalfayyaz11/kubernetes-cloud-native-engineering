Deployment Enforcement Observation
----------------------------------
Higher-level Deployment objects can be admitted while their ReplicaSets
fail to create non-compliant Pods.

The effective security control is applied when Pod admission occurs.

Mixed Policy Observation
------------------------
enforce determines whether a workload is allowed.

warn can return policy warnings to the requesting client without blocking.

audit can annotate admission decisions for audit processing when API server
audit logging is configured.

- non-root execution
- seccomp RuntimeDefault

- privilege escalation prevention
- namespace-level Pod Security Standards
- enforcement, warning, and audit policy modes
